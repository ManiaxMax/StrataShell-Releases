# Strata Shell Releases

Official distribution repository for [Strata Shell](https://github.com/ManiaxMax/StrataShell) installers, portable packages, and update feeds.

## Downloads

Official releases, verified setup executables, and package checksums are published under **[Releases](https://github.com/ManiaxMax/StrataShell-Releases/releases)**.

## About Strata Shell

Strata Shell is a wallpaper-driven Windows replacement shell built around a fixed Center Stage, persistent side widgets, logical workspaces, and recoverable default-shell installation.

> This repository contains only compiled release distributions and manifests.
