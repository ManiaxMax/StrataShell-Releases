# STRATA Shell 1.0.0

Official initial release of STRATA Shell.

## Included Artifacts
- **StrataShell-Setup-1.0.0-win-x64.exe**: Standalone self-testing installer
- **StrataShell-1.0.0.zip**: Portable self-contained release bundle
- **SHA256SUMS.txt**: Cryptographic checksums

## Features & Capabilities
- **Center Stage Workspace Window Management**: Deterministic single/split-slot window placement, smooth animations, and workspace isolation across 10 virtual workspaces.
- **Dynamic Live Wallpaper Theming**: Automatically extracts and propagates full light/dark color palettes and accent glow across all first-party and native surfaces on wallpaper change.
- **Curated Official Wallpapers**: Includes official `STRATA_LOGO_DARK.jpg` and `STRATA_LOGO_LIGHT.jpg`.
- **First-Party Application Suite**:
  - STRATA Terminal (with elevated mode and dynamic prompt)
  - STRATA Text Editor
  - STRATA Snipping Tool (instant capture overlay)
  - STRATA Files (marquee drag-to-select, file previews, and asynchronous enumeration)
  - STRATA Paint, Video Player, and Photo/Image Viewer
- **Peripheral Awareness Widgets**: AI Command assistant (Codex/Claude/OpenAI), YouTube persistent media, Weather, Calendar, and System Resource monitoring.
- **Top Rail Status & Application Tray**: Unified grouping, hardware filtering, and status controls.
- **Safe Recovery System**: Isolated self-contained maintenance launcher, emergency Explorer recovery (`Ctrl+Alt+Shift+Delete`), and three-failure automatic watchdog protection.
