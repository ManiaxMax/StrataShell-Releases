# STRATA Shell 1.0.4

Official release package for STRATA Shell.

## Included Artifacts
- **StrataShell-Setup-1.0.4-win-x64.exe**: Standalone self-testing installer
- **StrataShell-1.0.4.zip**: Portable self-contained release bundle
- **SHA256SUMS.txt**: Cryptographic checksums

## Highlights
- Unauthenticated release feed streaming from GitHub
- Stable and Preview update channel selection in Settings
- First-party application suite: Paint, Video Player, Photo/Image Viewer, Terminal, Text Editor, Snipping Tool
- Two approved STRATA wallpaper variants (Light / Dark)
