# Strata Shell 1.0.3

This release introduces Display settings refinements and fully silent in-place updates.

## Highlights
- **Settings > Display**: Cleaned header by removing subtitle and removed external Windows monitor configuration shortcuts.
- **Packaging**: Fully self-contained .NET 9 desktop runtime and 40 full 4K Strata wallpapers.
- **Silent Updates**: Fully automated in-place update application with seamless bootstrap version delegation.
