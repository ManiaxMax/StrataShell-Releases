# STRATA Shell 1.0.26

This Stable release promotes the tested Beta source through `472d1b6`, with matching 1.0.26 Shell, Launcher, Maintenance and Setup components.

## Files and window management

- STRATA Files offers Open With for one selected file, including compatible STRATA apps and registered Windows apps. Always use remembers the extension only in STRATA Files; Use STRATA Files defaults clears that override.
- Directional tiled movement enters the destination's leading or trailing slot according to direction, shifts a lone destination window and preserves swaps, exchanges and Dynamic boundary insertion.
- Wide and Dynamic layouts use the configured slot gap at their usable outer edges. Center Stage retains its widget alignment. Covered widget pixels are clipped while exposed content remains usable.
- First-party captions coalesce live-wallpaper moves through the existing floating and snap lifecycle. Task Manager opens file locations in STRATA Files, and optional app discovery checks local availability.

## Wallpaper, widgets and materials

- Live wallpapers use shared Windows frame-server playback on full-resolution GPU surfaces, with deferred opening, independent consumer requests, looping and final-consumer teardown.
- High-quality live window/widget blur shares the wallpaper's GPU frost. Other quality modes, High Contrast and unsupported paths retain still-frame frost. Live-to-still transitions retain outgoing imagery until completion.
- Eligible widget, shadow, rail and dock composition reuses bounded native-resolution textures. Fractional placement, static wallpapers and expansion storage receive related corrections while enlarged/unsupported paths retain their original renderer.
- Frost snapshots share immutable image data, theme publication avoids redundant resource work, and speculative preloading yields to active wallpaper motion.
- Clock formatting, spectrum continuity, calendar/theme propagation, wallpaper transitions and workspace return receive refinements. All 30 screensaver effects are retained, with pacing and input-desktop safeguards.

## Packages and limits

- `StrataShell-Setup-1.0.26-win-x64.exe` is the full self-testing Setup and uninstaller.
- `StrataShell-1.0.26.zip` is the self-contained updater and portable bundle.
- Both contain the .NET 10 Desktop runtime, privacy-safe defaults, reviewed recovery tools and exactly 24 approved 4K wallpapers. Existing settings are preserved.
- All 25 interface catalogs contain 4,460 messages. Native-speaker editorial review remains open.
- Installation retains the existing explicit terms and desktop-shell risk acceptance. Update archives require STRATA signatures; Windows Authenticode publisher signing is not configured.

STRATA remains experimental alpha software. Clock expansion stutter and the 60 FPS goal remain open. Physical input/DPI, installed visual behavior, native screen-reader behavior, third-party Open With launches and hardware/GPU paths require acceptance in the target environment. Source, package and isolated installer checks are separate from installed acceptance. Publication does not install, activate or restart STRATA Shell.
