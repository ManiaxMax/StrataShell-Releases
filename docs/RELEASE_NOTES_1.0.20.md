# STRATA Shell 1.0.20

This Stable release refines STRATA Sphere, Browser, Files, and first-party surfaces, adds optional 3D Glass styling, and improves installer removal of locked directories.

## Sphere and window behavior

- Refined native app input, resizing, helper-tab lifecycle, and fullscreen transitions in Sphere.
- Improved rail visibility and window layering during Sphere and desktop transitions.

## Browser, Files, and first-party apps

- Expanded Browser bookmark editing, new-tab destinations, and shortcut handling.
- Improved STRATA Files navigation for Computer, drives, and removable storage.
- Polished media, image, paint, screenshot, terminal, calendar, and task-manager surfaces.

## Appearance and maintenance

- Added optional 3D Glass material and Bloom refinement, with startup and rendering-cost improvements.
- Uninstall now defers removal of locked empty directories so the full Setup can complete cleanup after processes exit.
- Preserves existing personal settings. Fresh installations use the reviewed, privacy-safe defaults and only the two approved STRATA wallpapers.

## Complete Stable package

- `StrataShell-Setup-1.0.20-win-x64.exe`: self-contained Setup and uninstaller with the .NET 10 runtime.
- `StrataShell-1.0.20.zip`: self-contained updater and portable bundle with the .NET 10 runtime.
- Release manifest, validation report, and SHA-256 checksums accompany the packages.
