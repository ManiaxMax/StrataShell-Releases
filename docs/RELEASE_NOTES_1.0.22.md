# STRATA Shell 1.0.22

This Stable release promotes the Preview work since 1.0.21, including the refreshed wallpaper library, more reliable Rail and Dock behavior, and first-party app refinements.

## Desktop and apps

- Improved Rail/Dock sizing, hover behavior, Light appearance, and recovery across mode and display transitions.
- Kept first-click Rail actions responsive during Dock refresh, and kept the tray chevron pointing up in Floating mode.
- New app windows target the selected active monitor; Floating windows and reopened STRATA apps are placed on that display.
- Refined tab overflow and windowed Sphere behavior across first-party apps.
- STRATA Files opens folders and new tabs with the newest Modified items first.

## Wallpaper library and packaging

- Replaced the two legacy logo wallpapers with 24 approved 4K glass wallpapers: Light and Dark variants for 12 colors. Fresh installs default to Dark Blue.
- Preserved one wallpaper library independent of appearance; existing personal wallpapers and settings remain user-owned.
- The Stable installer and portable bundle include the complete approved wallpaper set and a self-contained .NET 10 runtime. Lightweight Preview updates continue to exclude both.

## Release assets

- `StrataShell-Setup-1.0.22-win-x64.exe`: self-contained Setup and uninstaller.
- `StrataShell-1.0.22.zip`: self-contained updater and portable bundle.
- SHA-256 checksums, a release manifest, and an isolated installer validation report accompany the packages.

Source and isolated automated validation do not replace physical installed-shell acceptance. This publication does not activate or restart the running shell.
