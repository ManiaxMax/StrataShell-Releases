# STRATA Shell 1.0.10

Stable promotion introducing the new STRATA Task Manager & Performance Monitor, STRATA Chromium Browser with Extension support, Media Player audio integration, custom themed UI scrollbars and typography, and refined performance presets.

## STRATA Task Manager & Performance Monitor

- **Hardware Telemetry & Live Graphs**: TMOG-inspired high-frequency telemetry tracking CPU, GPU, Memory, Disk, and Network usage with real-time waveform visualization.
- **Process Oversight**: Full process hierarchy and resource metrics with quick process inspection, termination policy, and critical system process protection.
- **Dedicated Keybinding & Launcher Access**: Launchable instantly via `Super + Shift + Escape` or through the technical application launcher catalog.

## STRATA Chromium Browser & Extensions

- **Integrated Chromium Web Engine**: Native WebView2 browser surface supporting multiple tabs, bookmark management, history, and configurable search engines.
- **Chrome & Edge Extension Support**: Install extensions directly via Web Store URLs or 32-character extension IDs with automated CRX package extraction, metadata sanitization, and action popups.
- **Security & Navigation Policies**: Clear URL classification with internal, secure, and web security indicators.

## Custom Themed Controls & UI Refinements

- **Cyber Themed ScrollBars**: Seamlessly integrated scrollbars adopting the live wallpaper palette and glow.
- **STRATA Files Sorting & Layout**: Fixed column header click sorting in details view, decoupled from marquee selection, with smooth visual feedback.
- **Performance Tiers**: High, Balanced, Low, and Custom rendering modes with automatic preset detection and dynamic graphics tuning.
- **Screensaver Optimizations**: Streamlined background particle passes and render loops for reduced GPU load when idle.

## Complete Stable Package

- StrataShell-Setup-1.0.10-win-x64.exe: Full self-contained Setup and uninstaller with the compatible .NET runtime included.
- StrataShell-1.0.10.zip: Complete self-contained updater and portable bundle with the compatible .NET runtime included.
- RELEASE_MANIFEST.json, VALIDATION_REPORT.json, individual Setup checksum, and unified SHA256SUMS.txt.
- Existing installations retain personal settings; only fresh profiles receive the approved portable defaults.
