# STRATA Shell 1.0.25

This Stable release includes all Beta source through the October 25 release, with matching 1.0.25 Shell, Launcher, Maintenance and Setup components.

## Desktop and personalization

- Dock and Rail have independent positions, scale, backgrounds and auto-hide. Split Rail alignment, dock icon centering, previews and popup lifetime are refined across every edge.
- Widgets offer individual designs, borders and appearance controls, complete resets and shared Settings/context-menu actions while preserving saved placement and expansion choices.
- Tiled layouts share a default across monitors with explicit individual overrides. Full-width layouts use consistent outer and internal spacing, with capacity checks before layout changes.
- Wallpaper Studio provides the fullscreen wallpaper workflow with live theme application. Quick Menu text stays sharp with bloom, and brightness and glass behavior are improved.
- All 30 original screensaver animations are retained and polished, with reduced raster/compositing cost and bounded rendering caches.

## Apps and updates

- Calendar presentation, theme changes and compact layouts are refined. First-party window lifecycle, native Sphere hosting, app discovery and tiled restoration receive reliability fixes.
- Application icons can follow STRATA styling. Command search, spectrum visualizers and workspace tools have expanded controls and coverage.
- The prerelease channel is now named Beta; saved Preview selections remain compatible. Launcher continues to check Stable only.
- Optional automatic Stable update checks offer Every Launch or Weekly on Sunday. They default off, report availability in Updates and never automatically download or install.
- All 25 interface catalogs contain 4,305 messages. Native-speaker editorial review remains open.

## Release assets and limits

- `StrataShell-Setup-1.0.25-win-x64.exe`: self-contained Setup and uninstaller.
- `StrataShell-1.0.25.zip`: self-contained updater and portable bundle.
- Both include the .NET 10 Desktop runtime, safe defaults, reviewed recovery tools and exactly 24 approved 4K wallpapers. Existing settings are preserved. Checksums, a release manifest and isolated installer validation accompany the release.
- Installation continues to require explicit acceptance of the existing STRATA end-user terms and desktop-shell risk notice.

STRATA remains experimental alpha software. Signed update archives are mandatory; Windows Authenticode publisher signing is not configured. Physical multi-monitor input/DPI, installed visual behavior, native screen-reader behavior and hardware/GPU paths still require acceptance. Source and isolated tests are not installed acceptance. Publication does not install, activate or restart STRATA Shell.
